# NASA Gallery Image Downloader

A high-performance, multithreaded Python utility designed to search and download high-resolution space photography directly from the official NASA API endpoint.

## 📖 Story
As you might have guessed, this project was born out of pure boredom during a spring break because I wanted to collect some cool space images. Since I didn't know anything about programming at the time, the original version was 100% made by copy-pasting code generated by various AI models. 

Fast forward to today: as I am preparing for my future software engineering journey, this project has been completely refactored! We threw out the old, slow browser automation (Selenium) and rebuilt the entire core to use NASA's direct API. It is now faster, highly stable, and production-grade. The permissive MIT license is included, so feel free to modify it or experiment with it!

## 💾 Storage Recommendation
For a full gallery crawl, have at least **100 GB** of free space available. If you want to be absolutely safe—especially if you plan to download original uncompressed files or full-resolution masters—consider archiving on a drive with **250–500 GB** or more.

## ✨ Main Features
- **Official NASA API Integration:** Direct server communication that bypasses visual web-scraping entirely. Completely immune to future NASA website redesigns.
- **Advanced Multithreading:** Spawns asynchronous background worker pipelines to process parallel downloads at maximum network speeds.
- **Structural Integrity Validation:** Automatically validates the binary structure of downloaded images via Pillow to filter out corrupted files or thumbnails below your size thresholds.
- **Thread-Safe Log Engine:** Utilizes atomic locks (`threading.Lock`) to write to tracking logs safely without concurrent file corruption risks.
- **Automatic Environment Management:** Self-contained dependency verification upon initialization. No separate setup script required.

## 🚀 Usage Guide

The script features an automated bootstrapper that will check and configure your Python dependencies (`requests` and `pillow`) automatically upon runtime launch.

### 1. Run with Default Parameters
Downloads images using the default keyword `nebula`, spawning `3` parallel threads into `./nasa_images_output`:
```sh
python nasa_image_downloader.py
```

### 2. Advanced Configurations
Customize your execution run via command-line arguments:
```sh
python nasa_image_downloader.py [-q QUERY] [-d DOWNLOAD_DIR] [-w WORKERS] [-r RETRIES] [--min-size PIXELS] [--retry-failed]
```

#### Examples
- **Custom search with 5 threads:**  
  `python nasa_image_downloader.py -q "apollo" -d "C:/SpacePhotos" -w 5`
- **Isolate and retry failed network drops only:**  
  `python nasa_image_downloader.py --retry-failed`

### 📋 Command-Line Arguments Matrix

| Flag | Long Option | Default | Type | Description |
| :--- | :--- | :--- | :--- | :--- |
| `-q` | `--query` | `nebula` | `str` | Search keyword for NASA assets (e.g., mars, saturn). |
| `-d` | `--dir` | `nasa_images_output` | `str` | Target local storage directory path for binary files. |
| `-w` | `--workers` | `3` | `int` | Number of concurrent processing download threads. |
| `-r` | `--retries` | `3` | `int` | Maximum network failure download retries allowed. |
| | `--min-size` | `100` | `int` | Minimum acceptable resolution dimension in pixels. |
| | `--retry-failed` | *False* | `flag` | Re-queues only the assets listed in `failed_downloads.txt`. |

### 📂 Operations Log Files
All runtime logs are saved dynamically inside your chosen target download directory:
- `scraper_log.txt`: Rotating event logger (Max 2MB, tracking 3 historical generations).
- `downloaded_images.txt`: Manifest registry storing URLs of successfully processed assets.
- `failed_downloads.txt`: Operational exception log containing dropped URLs (Targeted via `--retry-failed`).
